Call

State: idle
Hold the button (or hold Space), speak, release to send. This exercises the same socket path Twilio media would. No resampling needed — the backend hands your webm/opus straight to the Whisper API, which decodes it.

Barge-in: not supported by design — this is turn-based push-to-talk, so you can't interrupt a reply. That's an architecture answer, not a bug to test.
